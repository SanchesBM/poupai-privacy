Política de Privacidade

Última atualização: 18/05/2026

Quem somos

O PouPaí é um aplicativo de comparação de preços entre supermercados, permitindo ao usuário encontrar melhores ofertas, salvar favoritos e organizar listas de compras com praticidade.

Dados coletados

  • Nome
  • E-mail
  • Foto de perfil (quando fornecida pelo Google Login)
  • Produtos e mercados favoritos
  • Listas de compras criadas pelo usuário
  • Dados técnicos necessários para funcionamento do aplicativo

Como utilizamos os dados

Utilizamos os dados para autenticação segura, sincronização de listas, personalização da experiência, melhoria do aplicativo e funcionamento adequado dos serviços oferecidos.

Compartilhamento

O PouPaí não comercializa dados pessoais dos usuários com terceiros.

Segurança

Aplicamos medidas técnicas razoáveis para proteger as informações dos usuários contra acessos não autorizados.

Exclusão de conta

O usuário pode solicitar a exclusão da conta e dos dados associados diretamente pelos canais oficiais disponibilizados pelo aplicativo.
