Política de Privacidade

Sua privacidade é importante para nós. Esta política explica como o PouPaí coleta, utiliza e protege suas informações.

Quem somos

O PouPaí é uma plataforma de comparação de preços entre supermercados, criada para ajudar usuários a economizar nas compras.

Dados coletados

  • Nome
  • E-mail
  • Foto de perfil (Google Login)
  • Favoritos
  • Listas de compras
  • Dados técnicos básicos para funcionamento

Como usamos os dados

Os dados são utilizados para autenticação, sincronização das listas, personalização da experiência e melhoria contínua da plataforma.

Compartilhamento

Não comercializamos dados pessoais com terceiros.

Segurança

Utilizamos práticas de segurança adequadas para proteger as informações dos usuários.

Exclusão de conta

O usuário pode solicitar a exclusão da conta e dos dados associados pelos canais oficiais do aplicativo.
